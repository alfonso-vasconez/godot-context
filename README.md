# godot-context

## Descripción
Este repositorio contiene un script en Python diseñado para procesar y resumir el contexto de proyectos en Godot Engine. Ideal para organizar la estructura del proyecto o generar documentación rápida.

## Requisitos
* Python 3.x
* Godot Engine (proyectos en versión 3.x o 4.x)

## Cómo Ejecutarlo
1. Descarga o clona este repositorio.
2. Coloca el script `godot_summary.py` en la carpeta raíz de tu proyecto de Godot.
3. Abre la terminal y ejecuta:
   ```bash
   python godot_summary.py
